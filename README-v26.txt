NYTT:
- 62 recept från användarens köpta Anton Ekefäll-böcker, med bildutsnitt från böckerna för privat användning, näringsvärden och ingredienser.
- Recept urval enligt angivna matpreferenser, pesto, såser och cornflakes tillåtna.

- Godkänd översiktsaffisch: michael-voss-kettlebell-godkand.png.
- Ny cacheversion v26 för att inte fastna i äldre resurser.

VIKTIGT:
- Detta är ett nytt installationspaket, INTE en publicering till GitHub Pages.
- Kontrollera backup/export och import INNAN publicering.
- 24 återstående övningsillustrationer ingår inte som färdiggranskade.
- Bilder och recept från köpta böcker är endast för privat bruk. Publicera inte PDF-innehållet i ett öppet publikt repo.
- Om din GitHub Pages är offentligt åtkomlig ska receptbilderna och innehållet inte laddas upp där utan rättighetshavarens tillstånd.
- PDF-tolkningen är automatisk. Granska ingrediensrader och näringsvärden före skarp användning.
- Appen har inte genomgått fullständig Android-/Drive-integrationstest i denna miljö.
